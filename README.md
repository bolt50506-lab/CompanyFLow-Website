# CompanyFlow
`npm install && npm run dev` — Next.js 14 (App Router), TypeScript, Tailwind 3, Framer Motion, Lucide.
Contact form: POSTs to `/api/contact`; set `CONTACT_WEBHOOK_URL` (see `.env.example`). Unset = form says "not connected" and offers a mailto (confirm the address in ContactForm.tsx).
Testimonials intentionally omitted until real quotes exist.
